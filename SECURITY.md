# Política de Segurança

## Versões Suportadas

Este projeto é um painel acadêmico pessoal em desenvolvimento contínuo. Atualmente, apenas a versão mais recente do código no branch principal recebe atualizações de segurança.

| Versão | Suporte |
| :--- | :--- |
| Principal (Última) | ✅ Sim |

## Relatando uma Vulnerabilidade

**Por favor, não relate vulnerabilidades de segurança através das Issues públicas do GitHub.**

Se você identificar qualquer falha de segurança (como exposição indevida de dados, problemas de autenticação ou injeção de código), entre em contato de forma privada para que possamos corrigir o problema antes que seja exposto.

Você pode relatar a vulnerabilidade através da aba **Security** (Segurança) deste repositório, clicando em **"Report a vulnerability"** (Relatar uma vulnerabilidade), ou enviando um e-mail para o mantenedor do projeto.

### O que incluir no relatório:
- Descrição detalhada da vulnerabilidade.
- Passos para reproduzir o problema.
- Impacto potencial (ex: vazamento de notas, acesso não autorizado).
- Sugestão de correção (se aplicável).

## Escopo

Esta política cobre o código fonte disponibilizado neste repositório. Não cobrimos falhas originadas por má configuração de contas de usuário no Firebase ou problemas de infraestrutura de terceiros.
